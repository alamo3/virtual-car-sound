# IONIQ 6 N launch-control reference audio

These two WAVs are the audio assets linked directly from Hyundai N's public IONIQ 6 N product page, downloaded for local reference analysis. The page labels them Evolution (N Launch Control) and Lightspeed (N Launch Control). They are mixed promotional examples, not confirmed isolated synthesis layers or a dataset of speed/throttle states.

- Page: https://www.hyundai-n.com/en/models/n/the-all-new-ioniq-6-n
- Evolution: https://www.hyundai-n.com/inc/sounds/ioniq6n-sound-evolution.wav
- Lightspeed: https://www.hyundai-n.com/inc/sounds/ioniq6n-sound-lightspeed.wav

Both files are stereo 48 kHz / 16-bit PCM, approximately 8 seconds. They are unmodified downloads. Their playback rights have not been established for redistribution or embedding in the project.
