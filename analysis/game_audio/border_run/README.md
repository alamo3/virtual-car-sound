# Border Run engine loops

Six unmodified mono WAV files downloaded from the `public/sfx/engine/` directory
of [Border Run](https://github.com/yashimosh/border-run). They are short game
engine loops, approximately 0.62–0.86 seconds each. Their recording perspective,
RPM, load and suitability for an EV sound are unknown.

The game's [credits](https://github.com/yashimosh/border-run/blob/main/CREDITS.md)
attribute the files to OpenGameArt's "Racing car engine sound loops" and list
them as CC0. The original OpenGameArt page could not be checked independently,
so confirm the upstream license before redistribution or release.

These are raw source files for audition, not a finished driving sound or a
matched throttle-on/throttle-off sample bank.
