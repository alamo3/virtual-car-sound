# IONIQ 5 N interior auditions

These are complete recordings from the BOOM Library Electric Vehicles package
in `~/Downloads/Boom Library - Electric Vehicles (WAV)/Electric Vehicles [Boom Library]/`.
They are audition copies, not isolated sound-generator samples or RPM/load loops.
Vehicle and cabin sounds can be present. The original AmbiX recordings remain
untouched in Downloads.

The originals are 96 kHz, 24-bit, four-channel AmbiX. The audition files use a
fixed first-order AmbiX ACN/SN3D stereo matrix (W ± Y and front X), 48 kHz,
24-bit PCM, and the same 10 dB gain increase after decoding. This is a simple
speaker-oriented decode, not binaural rendering. There is no noise reduction,
pitch shifting, dynamics processing, looping, or editing. The loudest decoded
file peaks about 3.6 dB below full scale. The files can still be quiet; adjust
playback volume carefully. Original commercial audio should not be redistributed.
