# Evolution rev: perspective comparison

These are synchronized versions of the same 11.8-second BOOM IONIQ 5 N
Evolution rev take. Each has a single fixed gain chosen to match the complete
file's RMS level at -21 dBFS; no compression, noise reduction, or EQ was used.

- `evolution_cabin_original_direction.wav`: the same AmbiX decode orientation
  used for the earlier stereo auditions, level matched.
- `evolution_cabin_opposite_direction.wav`: the same cabin recording decoded
  180 degrees in the horizontal plane. This is an AmbiX decode direction; the
  actual microphone's physical orientation is not established.
- `evolution_rear_bumper.wav`: the separately recorded rear-bumper left/right
  microphones from the same take. These are exterior, not cabin microphones.

The two cabin decodes use first-order ACN/SN3D W, Y, and X. For the original
direction, left/right are 0.707W + 0.5X ± 0.5Y; the opposite direction changes
the signs of X and Y. Output is 48 kHz 16-bit PCM. The highest sample peaks are
-1.9, -2.7 and -2.1 dBFS respectively. Originals are untouched in Downloads.
These are field recordings, potentially including road and motor sounds, not
direct captures of the isolated virtual sound generator. Do not redistribute
commercial source material.
