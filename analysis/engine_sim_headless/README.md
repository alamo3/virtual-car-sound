# Offline Engine Simulator render

This experimental harness builds the engine physics, scripting system and audio synthesizer from a separately cloned AngeTheGreat Engine Simulator, without its graphical application or audio device. It copies only required source folders into a temporary directory and applies `linux-port.patch` there; it never changes the original checkout. The port replaces Boost filesystem with C++17 filesystem, fixes compiler-specific syntax and headers, and removes frame-latency compensation for deterministic offline stepping. It is not the stock application, a realtime engine, or a validated Linux port.

The harness compiles the checkout's `assets/main.mr` (currently Subaru EJ25), loads its configured exhaust impulse response, starts the engine, and free-revs it for 12 seconds; the transmission is not used to simulate a drive. Its log prints RPM every second. The harness limits master volume to 0.25; verify output levels when using another engine.

Requirements: Python 3, git, CMake, a C++17 compiler, Flex, Bison and installed CMake GoogleTest/GMock libraries. The upstream checkout must have its submodules initialized. SDL2, SDL2_image, graphics, a sound device and network access are not needed for this offline build.

Run from this repository:

```
.venv/bin/python analysis/engine_sim_headless/render.py ~/Documents/engine-sim --output /tmp/engine-sim-subaru.wav
```

The renderer refuses to overwrite an existing file. Source repository: https://github.com/ange-yaghi/engine-sim . Engine Simulator is Copyright 2022 AngeTheGreat (Ange Yaghi) and licensed under MIT; see its checkout's LICENSE. The WAV is generated by that software and uses its impulse response.
